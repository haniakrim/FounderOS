# FounderOS User Manual

FounderOS is a personal operating system for a one-person company. It runs your
business as a set of AI-assisted departments on one screen: comms, a client
funnel, social growth, finances, a searchable knowledge base, and a roster of
named agents. Everything lives in one local database on your machine.
